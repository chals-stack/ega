# Politique de sécurité

## Signaler une vulnérabilité

N’ouvrez pas d’issue publique pour une faille exploitable ou une exposition de données. Écrivez à **nazacharbel@gmail.com** avec la version concernée, les étapes de reproduction et l’impact estimé. Un accusé de réception est visé sous sept jours.

## Périmètre actuel

EGA V1 est un MVP de démonstration : données dans `localStorage`, paiements déclaratifs, aucune authentification serveur et aucun encaissement réel. N’utilisez pas de données financières réelles, de code PIN ou de code à usage unique.

Une mise en production financière nécessite notamment un backend sécurisé, une authentification forte, une journalisation serveur, une politique de rétention, des contrôles d’accès et une validation réglementaire adaptée à la zone BCEAO.

# Contribuer à EGA

Merci de contribuer à EGA. Avant toute modification, ouvrez une issue décrivant le besoin, son impact métier et les données concernées.

## Installation

1. Utiliser Node.js 22 ou supérieur.
2. Exécuter `npm install`.
3. Lancer `npm run dev`.
4. Avant une proposition de changement, exécuter `npm test` puis `npm run build`.

## Règles

- Conserver les montants en entiers XOF et séparer principal, pénalités et arriérés.
- Utiliser le fuseau `Africa/Lome` pour les règles d’échéance.
- Ne jamais ajouter de secret, de code PIN Mobile Money ou de donnée personnelle réelle.
- Prévoir les interfaces à partir de 280 px et respecter le contraste du texte.
- Documenter toute modification métier dans `CHANGELOG.md`.
